## 3. ข้อมูลเข้า (ตัวสร้างกลาง ใช้ร่วมทุก ticket)

ไฟล์ `versions9_1/inputs.py` (ไฟล์เดียว):

| ฟังก์ชัน | คืนค่า | ใช้กับ | กฎเวลา |
|---|---|---|---|
| `table(rnd)` | `ladder.table(rnd, end=2026-09-04)` + คอลัมน์ `seq_i` | ทุกกลุ่ม | ของ v9 |
| `cols(rnd, stock, kind)` | `kind="own"` = คอลัมน์ ridge v9 (เช้า: `feature_cols(rnd, s)` · บ่าย: ตัด `LATE`) · `kind="pooled"` = คอลัมน์ HGB v9 + `is_kbank` | A, B, E | ของ v9 |
| `windows(t, rnd, cols, L=20)` | `(n, L, p+2)`: แถวของหุ้นเดียวกัน **20 วันทำการก่อนหน้า d** ของ `cols` + `y_m` + `y_a` · หน้าต่างที่มีค่าหายแม้ช่องเดียว = ทิ้งแถวนั้น | B, E เช้า | ใช้แถว `date < d` เท่านั้น · `y_a(d−1)` รู้ตั้งแต่ปิด d−1 |
| `minute_seq(t)` | `SEQ[seq_i]` ของ v9 `(2, 155)` | B (1m), E บ่าย | ของ v9 (`bar_end ≤ 12:30`) |
| `session_candles(stock)` | แท่งครึ่งวัน: เช้า (เปิดแรก, สูง, ต่ำ, `P_d`, ปริมาณ, มูลค่า) · บ่าย (…, `C_d`) | C04 | แท่งเช้า known_at 12:30 · แท่งบ่าย known_at ปิดตลาด |
| `daily_ohlc(stock)` | OHLCV รายวันจาก `load_official` | E06 เช้า | แถว `date < d` |
| `adjust_xd(prices, D, anchor)` | ปรับราคาย้อนหลังทุกแถวก่อนวัน XD ด้วยตัวคูณ `(C_{d−1} − D_d) / C_{d−1}` | C04, E06 | ใช้แค่ `D_d` ที่รู้ก่อน d |

- **ทำไม L = 20:** เท่ากับหน้าต่าง 20 วันของภาพ JKX และหน้าต่างปริมาณเฉลี่ยของ v9 · ไม่ลองหลายค่า (Rossi–Inoue: ลองหลายหน้าต่างแล้วเลือก = snooping)
- **ทำไมใส่ `y_m` และ `y_a` ย้อนหลังทั้งคู่:** โมเดลลำดับเวลาต้องเห็นประวัติของเป้า · ทั้งสองค่ารู้ก่อนเวลาตัดของทั้งสองรอบ
- clip 1%/99% และปรับสเกลรายช่องบนหน้าต่างเทรนของแต่ละรอบ fit (สถิติจากทุกแถวในทุกหน้าต่างของชุดเทรน)

## 4. ตัวรัน

ไฟล์ `versions9_1/zoo.py` · CLI:

```
OMP_NUM_THREADS=1 .venv/bin/python -W ignore -m src.task3.versions9_1.zoo <round> --group A|B|C|E|R [--only ID ...] [--smoke] [--pc RHO2]
```

- **walk-forward เดียวกับ v9:** หน้าต่างขยายจาก 2017-04 · สัปดาห์ที่ให้คะแนน 2019-01-01 → 2026-09-04 ต่อเนื่องในการรันเดียว
  (หน้าต่างขยาย = รันรวดเดียวได้ค่าเท่ากับรันสองช่วงแยก) · เทรนด้วยแถวก่อนวันแรกของสัปดาห์ · ≥ 120 วันเทรน
- **hyperparameter:** เลือกปีละครั้ง (สัปดาห์แรกที่ให้คะแนนของปี) บน 3 ช่วง 10% ท้ายหน้าต่าง · MSE เฉลี่ยต่ำสุด ·
  โมเดลที่ early stop ใช้ epoch/รอบเฉลี่ยของ 3 ช่วง · โมเดลรวมสองหุ้นแบ่งตามวันที่ = `ladder.select` ทุกอย่าง
- **ความถี่ fit ใหม่** (แต่ละ ticket ระบุ): `week` / `month` / `year` / `none` (foundation model)
- `walk()` และ `select()` ของ v9.1 คัดมาจาก `ladder.walk` / `ladder.select` แล้วแก้แค่สามจุด: (1) `train/grid` มาจากทะเบียนโมเดลของ v9.1
  (2) `fit_key` ตามความถี่ของสเปก (3) รายชื่อโมเดลที่เลือกจำนวนรอบ/epoch มาจากทะเบียน (`iterative=True`) แทนชุด `hgb/mlp/cnn` ที่เขียนตายตัว · ห้ามแก้อย่างอื่น
- **ทะเบียนโมเดล:** `MODELS = {"A01": dict(kind=..., cols="own"|"pooled", input="tab"|"win"|"min"|"img"|"fm", refit=..., grid=[...], train=fn), ...}`
  · ทุก `train` คืน `predict` หรือ `(None, best_iter, val_mse)` ตาม interface ของ `ladder.train`
- **ผลลัพธ์:** `artifacts/task3/v9_1/<run id>/` = `preds.parquet` · `daily.parquet` · `metrics.json` · `hp.json`
  (ค่าที่เลือก + epoch + % epoch 0) · `diag.json` (SD ของ ŷ / SD ของ y, เวลา) · `run_manifest.json` (commit, dirty, seed,
  เวอร์ชันแพ็กเกจ, hash ของ weight) · run id = `v91-<round>-<group>-<yyyymmdd>-a` · มีอยู่แล้ว = ไม่เขียนทับ
- **ความทำซ้ำได้:** seed ตาม ticket · `torch.use_deterministic_algorithms(True)` · `torch.set_num_threads(1)` · รันบน CPU
  (ยกเว้น A14/C ที่ ticket อนุญาต MPS) · รันซ้ำต้องได้ค่าเดิมทุกบิตบน CPU

## 5. การให้คะแนน (เหมือน v9 + เพิ่ม)

ไฟล์ `versions9_1/score.py`:

1. **ช่วง:** เลือก 2019-01-01 → 2022-12-31 · ยืนยัน 2023-01-01 → 2026-09-04 (+ แยก 2025-08-25+ และก่อน/หลัง 2024-03-25 เหมือน `confirm.SPLITS`)
2. **วันที่ใช้เทียบ:** วันที่**ทุก**สเปกในรอบนั้นและ R0–R4 มีค่าทาย (common days) · รายงานวันของตัวเองด้วย · ถ้า common days
   หายเกิน 10% เพราะสเปกเดียว ให้รายงานแบบไม่มีสเปกนั้นอีกชุด
3. **ต่อสเปก:** skill รวมสองหุ้นเทียบ R0 (`ladder.metrics`) · SE block bootstrap · Clark–West p · รายปี · รายหุ้น · trim 1% ·
   **ผลต่างจับคู่กับ R3** ± SE (block 5 วัน, 10,000 รอบ, seed 340 แบบ `pick.py`)
4. **ตรวจโมเดลยุบ:** `sd(ŷ)/sd(y)` รายปี · < 5% = ธง "ยุบเป็นค่าเฉลี่ย"
5. **ตรวจหยุดเร็ว:** % ของการเลือกรายปีที่ epoch/รอบที่ดีที่สุด = 1 (= v8 CNN ที่หยุดที่ epoch 0)
6. **Model Confidence Set:** `arch.bootstrap.MCS(losses, size=0.10, reps=10000, block_size=5, method="R", bootstrap="stationary", seed=340)`
   · loss = `se` รายวันรวมสองหุ้นบน common days · สมาชิก = ทุกสเปก + R0–R4 · แยกรอบ แยกช่วง
7. **หักผลจากการลองหลายแบบ:** Bailey–López de Prado ด้วย N ใน §2 · รายงานอย่างเดียว

## 6. test (ต้องผ่านก่อนรันสเปกจริงตัวแรก)

ไฟล์ `tests/test_task3_v9_1.py` (รันด้วย `.venv/bin/python -m pytest`):

1. **ตัวรันถูก:** `zoo --group R` บนช่วงเลือก ได้ `yhat` ของ ridge, huber (เช้า) และ ridge, hgb, cnn (บ่าย) **เท่ากับ**
   `artifacts/task3/v9/v9-<round>-20261028-a/preds.parquet` ทุกบิต
2. **หน้าต่างไม่เห็นอนาคต:** สุ่ม 50 แถว · ตัดตารางเหลือ `date < d` แล้วสร้าง `windows` ใหม่ ต้องได้ค่าเท่ากับที่สร้างจากตารางเต็ม ·
   ใส่ NaN ให้แถว d เองแล้วหน้าต่างของ d ต้องไม่เปลี่ยน
3. **แท่งเทียนและภาพไม่เห็นอนาคต:** `F.truncate(raw, cutoff)` แล้วสร้าง `session_candles` / ภาพ E06 / spectrogram E07 ใหม่
   ต้องเท่ากับของเต็ม (test เดียวกับ v9 M1)
4. **ปรับ XD:** วัน XD ที่รู้จริง 1 วันต่อหุ้น · แท่งก่อนหน้าคูณด้วยตัวคูณถูกต้อง · แท่งสุดท้ายก่อนทาย = anchor
5. **ทำซ้ำได้:** สเปก torch ตัวเล็กหนึ่งตัวรัน `--smoke` สองครั้งได้ค่าเท่ากันทุกบิต
6. **smoke ทุกสเปก:** `--smoke` (ม.ค.–ก.พ. 2019) ทุกสเปกรันจบและได้จำนวนค่าทาย > 0 · ไม่ให้คะแนน

## 7. positive control (ไม่นับเป็นสเปก · ไม่เปลืองช่วงเลือก)

- เหมือน v9 `checks/positive_control.py`: ฝัง `y_c = y + b·x` · `x ~ N(0,1)` seed 340 · `b = sd(y)·√(ρ²/(1−ρ²))` · **ρ² = 2%**
- `x` ใส่เป็น feature ของวันนี้ (คอลัมน์ใหม่ใน `cols`) ให้ทุกสเปกที่รับ feature ของวันนี้ · สเปกที่เห็นแค่ภาพหรืออนุกรม
  (E06p, C01–C04) ใช้ `x = ค่าที่มองเห็นในข้อมูลเข้า` ตาม ticket ของมัน
- ให้คะแนนบน **2021–2022 เท่านั้น** (ประหยัดเวลา) · ผ่าน = skill บน `y_c` ลบ skill บน `y` ≥ **1%** (ครึ่งหนึ่งของ 2% ที่ฝัง)
- ตัวที่ไม่ผ่าน → รายงานว่า "แพ้เพราะฝึกไม่ขึ้น ไม่ใช่พิสูจน์ว่าไม่มีสัญญาณ" · ไม่แก้โมเดลหลังเห็นผลนี้ (ตั้งใจให้เป็นข้อมูลอธิบาย)
- รันก่อนสเปกจริงของแต่ละกลุ่ม · ผลไปที่ `artifacts/task3/v9_1/positive_control/`
