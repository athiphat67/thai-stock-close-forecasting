## 1. กฎออกแบบ (บทเรียนจาก v6–v8 · ใช้ทุกตัว)

1. **ต่อจาก ridge (residual):** `ŷ = ŷ_R2 + g(ข้อมูลเข้า)` · `ŷ_R2` = ค่าทาย walk-forward ของ R2 (ridge v9 รายหุ้น fit ทุกสัปดาห์)
   · `g` เทรนบน `y − ridge_ในตัวอย่าง` โดย ridge ที่ fit ณ วันตัดของรอบ fit นั้น (α ปีนั้นของ R2)
   · ข้อจำกัด: residual ในตัวอย่างเล็กกว่า out-of-sample เล็กน้อย · α ของ ridge ใหญ่ (shrink แรง) ผลจึงเล็ก · จดในรายงาน
2. **ตัวล้วน:** E02p และ E06p ไม่มี ridge: `ŷ = g(ข้อมูลเข้า)` = แบบที่เปเปอร์ใช้
3. `g` เห็นแค่ข้อมูลเข้าของตัวเอง + `is_kbank` ที่หัว · ไม่เห็น feature ของวันนี้ (feature อยู่ใน ridge แล้ว)
4. **ห้าม pool จนแกนเวลาหาย** · pool ได้แค่แกนเวลาบางส่วน หรือแกนราคา/ความถี่ · ก่อนหัวต้องเหลือ ≥ 5 ขั้นเวลา
5. **ทิศแยกจากขนาด:** ช่องที่เป็นขนาด (ปริมาณ, กำลังของความถี่) กับช่องที่มีเครื่องหมาย (return) อยู่คนละช่องเสมอ
6. ทุกตัวรายงาน `sd(ŷ − ŷ_R2)/sd(y)` (ส่วนที่ CNN เพิ่ม) และ % หยุดที่ epoch 1

### 4.2 โครงข่าย (ตาม JKX ภาพ 20 วัน)

- 3 block · แต่ละ block: Conv2d kernel 5×3 → BatchNorm → LeakyReLU(0.01) → MaxPool (2,1)
- ช่อง 64 → 128 → 256 · ชั้นแรก stride (3,1) dilation (2,1) · ชั้นอื่น stride 1 · padding ให้ flatten ของภาพ 64×60 = **46,080**
  ตามที่ JKX รายงาน (test ตรวจตัวเลขนี้) · ภาพบ่าย 64×90 ใช้ padding เดียวกัน ขนาด flatten ตามที่ได้
- Dropout 0.5 → Linear → **1 ค่า (ถดถอย)** · init Xavier
- **ต่างจาก JKX ข้อเดียวที่ตั้งใจ:** JKX จำแนกทิศ (softmax + cross-entropy) · เราถดถอย `y/sd(y)` ด้วย MSE เพราะคะแนนคือ RMSE
- Adam lr **10⁻⁵** (JKX) · batch 128 · ≤ 100 epoch · patience **2** (JKX) · **3 seed** (340–342, JKX ใช้ 5 แต่เวลาไม่พอ)
- validation ใช้ 3 ช่วงตามเวลาของ v9 (JKX สุ่ม 70/30 ซึ่งข้ามเวลา · เราไม่ทำ)

  · ทำซ้ำไม่ได้ทุกบิตบน MPS → รันซ้ำ 1 ปี รายงานส่วนต่างสูงสุดของ ŷ

## 5. E07 spectrogram (บ่ายเท่านั้น)

- STFT ของช่อง return ใน `S` (155 นาที) · Hann window 32 · hop 8 → 16 frame × 17 bin
- ช่อง 1 = `log(power + 1e-12)` ปรับสเกลบนหน้าต่างเทรน · ช่อง 2 = ผลรวม return ใน frame นั้น (มีเครื่องหมาย) ซ้ำตามแกนความถี่
  → ทิศอยู่คนละช่องกับขนาด (แก้ข้อบกพร่องของ v7 ที่ผสมกันใน 3×3 + BN)
- pool เฉพาะแกนเวลา (1,2) สองครั้ง → 16 frame เหลือ 4 · แกนความถี่ไม่ถูกยุบ
- residual บน ridge ตามกฎ §1

## 6. positive control (ต้องให้ ridge มองไม่เห็นสัญญาณ ไม่อย่างนั้นวัดส่วน CNN ไม่ได้)

- ฝัง `y_c = y + b·z` ด้วย `z` ที่**มองเห็นในข้อมูลเข้าของ CNN แต่ไม่อยู่ใน feature ของ ridge**:
  - เช้า: `z` = return 5 วัน `log(C_{d−1}/C_{d−6})` ปรับสเกล (เห็นในภาพ 20 วันและใน `W` · ridge มีแค่ข้อมูลของ d−1)
  - บ่าย: `z` = return 10:00 → 10:30 ของวันนี้ ปรับสเกล (เห็นใน `S` และภาพ 5 นาที · ridge มีแค่ `r_morning`, `r_last30`, `r_last60`)
- `b` ตั้งให้ ρ² = 2% · ให้คะแนน 2021–2022
- **ผ่าน** = (skill บน `y_c` − skill บน `y`) ของตัวนั้น ≥ 1% **และ** มากกว่าของ R2 บนเป้าเดียวกันอย่างน้อย 0.5%
  (แปลว่าส่วน CNN จับได้เอง ไม่ใช่ ridge จับผ่านความสัมพันธ์บางส่วน)
- ใช้ `z` ชุดเดียวกันกับตัวล้วน (E02p, E06p) โดยไม่ต้องมีเงื่อนไขที่สอง
