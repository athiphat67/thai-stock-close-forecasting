## 1. D01 ค่าเฉลี่ยตัวแทนกลุ่ม

- ตัวแทนกลุ่ม = สเปกที่ skill รวมสองหุ้นสูงสุดในกลุ่ม A, B, C, E บน**ช่วงเลือกเท่านั้น** (common days) · 4 ตัวต่อรอบ
  · B และ B (1m) นับเป็นกลุ่มเดียว · E และ E ล้วน นับเป็นกลุ่มเดียว
- `ŷ_D01 = (ŷ_A + ŷ_B + ŷ_C + ŷ_E) / 4` น้ำหนักเท่ากัน (combination puzzle: ไม่ fit น้ำหนัก)
- ช่วงยืนยันใช้ 4 ตัวเดิม ไม่เลือกใหม่ · ค่าทาย D01 บนช่วงเลือก**มีอคติจากการเลือก** (เลือกตัวแทนจากช่วงเดียวกัน) → รายงานแต่ไม่ใช้ตัดสิน
- ไม่ต้องเทรนเพิ่ม · คำนวณจาก `preds.parquet` ของ T01–T04

## 2. ตารางผล (ต่อรอบ × ต่อช่วง: เลือก / ยืนยัน / 2025-08-25+ / ก่อนและหลัง 2024-03-25)

| คอลัมน์ | ที่มา |
|---|---|
| skill รวม ± SE, CI 95% | `ladder.metrics` |
| ผลต่างกับ R3 ± SE | block bootstrap จับคู่ (T00 §5.3) |
| Clark–West p | `ladder.nw_p` |
| skill รายปี · รายหุ้น · trim 1% | `ladder.metrics` |
| อยู่ใน MCS 10% ไหม | §3 |
| `sd(ŷ)/sd(y)` · % หยุดที่ epoch 1 · positive control ผ่านไหม | `diag.json`, positive control |
| เวลาที่ใช้ | `run_manifest.json` |

- เรียงตามกลุ่ม แล้วตาม skill · ไม่ใส่สี "ผ่าน/ไม่ผ่าน" ในตารางหลัก (ไม่มีเกณฑ์ตัดสินส่งสอบ)
- กลุ่ม C มีตารางเพิ่ม: ช่วงหลังวันปล่อยของแต่ละตัว (T03 §2)

## 3. Model Confidence Set

- `arch.bootstrap.MCS` · `size=0.10` · `reps=10000` · `block_size=5` · `method="R"` · `bootstrap="stationary"` · `seed=340`
- loss = `se` รายวันรวมสองหุ้นบน common days · สมาชิก = ทุกสเปก + R0–R4 · แยกรอบ แยกช่วง
- อ่านผล: ถ้า R0 (ทาย 0) อยู่ใน MCS ของช่วงไหน = ช่วงนั้นไม่มีโมเดลใดดีกว่าทาย 0 อย่างแยกได้
- ถ้า common days ทำให้ข้อมูลหายมาก (T00 §5.2) รัน MCS อีกชุดที่ไม่มีสเปกนั้น
- ติดตั้ง `arch` (ขออนุญาต) · ถ้าติดตั้งไม่ได้ เขียน T-max MCS เอง (Hansen–Lunde–Nason 2011 §3) ≈ 40 บรรทัด + test กับตัวอย่างที่รู้คำตอบ

## 4. หักผลจากการลองหลายแบบ

- Bailey–López de Prado: ค่าสูงสุดที่คาดได้จาก N trial · N = 47 (เช้า) / 50 (บ่าย) ตาม T00 §2
- N อิสระที่แท้จริงต่ำกว่านี้ (สหสัมพันธ์ของค่าทายสูง) → รายงาน N จริงและ N ที่ประมาณจากสหสัมพันธ์เฉลี่ยของ ŷ (ภาคผนวก A.3)

## 5. ผู้สมัคร v10 (เกณฑ์ตั้งก่อนเห็นผล)

สเปกหนึ่งเป็นผู้สมัครเมื่อผ่าน**ทุกข้อ**บน**ช่วงยืนยัน**:
1. อยู่ใน MCS 10% และ R0 ไม่อยู่
2. ชนะ R3 เกิน 1 SE ของผลต่างจับคู่
3. skill > 0 ทั้ง 3 ช่วงย่อยของการยืนยัน (2023 / 2024 / 2025-01 → 2026-09-04)
4. positive control ผ่าน · ไม่ติดธงยุบ
5. (กลุ่ม C) ผ่านข้อ 1–3 บนช่วงหลังวันปล่อยด้วย

- ผู้สมัครยังส่งสอบไม่ได้ · ต้องชนะ R3 ต่อบน**เดือนใหม่หลัง 2026-11-20** ตามแผน v10
- ไม่มีผู้สมัคร = ผลที่คาดไว้ และรายงานได้ตรง ๆ

## 6. การตรวจทาน (Opus xhigh · แบบที่ทำกับ v9)

ตรวจ**ก่อน**เปิดอ่านตารางผลจริงของแต่ละกลุ่ม:
1. ข้อมูลรั่ว: `inputs.windows`, ภาพ E06, spectrogram E07, แท่งครึ่งวัน C04, residual ของ E (ridge ในตัวอย่างใช้แค่แถวเทรน)
2. perturbation test แบบ v9: เปลี่ยนค่าแถวหลังวันตัดแล้วค่าทายต้องไม่เปลี่ยน · สุ่ม 3 สเปกต่อกลุ่ม
3. ตัวรันทำซ้ำได้ (test 1 และ 5 ของ T00)
4. foundation model: ตรวจว่า context ไม่มีวัน d และจดวันปล่อยครบ
5. ผลการตรวจจดใน EXPERIMENT_LOG ก่อนตารางผล
