# Task 3 v9.2 — โมเดลรอบเช้าที่ไม่ต้องใช้ S50

สรุป ณ 2026-11-11 · โค้ด: `fit.py` (`DEPLOY_SPECS`), `predict.py` (`PRIMARY`), `fetch_yahoo.py`

## 1. ปัญหา

- โมเดลหลักรอบเช้าของ v9 (Huber) ต้องใช้ `fut_post` คือราคา S50 futures หลังตลาดหุ้นปิด
- ราคานี้ได้จาก TradingView แบบเสียเงินเท่านั้น ระบบจริงจึงดึงไม่ได้ และรอบเช้าต้องใช้โมเดลสำรอง (`ols_atc`) ทุกวัน
- Huber ของ KBANK ยังต้องใช้ราคาหุ้นแบงก์เมื่อวาน (`peer_prev`) ซึ่งระบบจริงก็ไม่มีเหมือนกัน

## 2. สิ่งที่ทำ

- **โมเดลหลักรอบเช้าใหม่ `huber_lite`:** ใช้ Huber ตัวเดิม (alpha เดิม: KBANK 1000, ADVANC 100) แต่ตัด `fut_post` และ `peer_prev` ออก
  - เหลือ feature 14 ตัว: `spx, thd, thb, n225, hsi, on_prev, id_prev, range_prev, vol_prev, monday, gap_days, long_break, xd, atc_push`
  - ค่า alpha ที่เลือกจาก 3 ช่วง validation ของปี 2026 ได้ค่าเดิม จึงไม่ต้องเปลี่ยน
- **เทรนได้ถึง 2026-10-21 และเริ่มจากปี 2017** (Huber เดิมเทรนถึงแค่ 08-31 และเริ่มปี 2019 ตามข้อมูล futures)
- **ตัวดึงข้อมูลฟรี `fetch_yahoo.py`:** ดึงจาก Yahoo ได้ครบทุกอย่างที่ต้องใช้
  - ราคารายวันทางการ
  - แท่ง 1m ของ 7 วันล่าสุด และแท่ง 5m ของ 60 วันก่อนหน้า
  - ตลาดต่างประเทศ 5 ตัว
  - วัน XD
- โมเดลสำรองยังเป็นตัวเดิม: รอบเช้า `ols_atc` × 0.7 และรอบบ่าย HGB กับ `ols_small`
