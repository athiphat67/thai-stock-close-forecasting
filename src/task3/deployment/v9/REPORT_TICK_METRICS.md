# Task 3 v9 — ปัดราคาเป็นช่องราคา (tick) + ผลวัด RMSE / MAE

อัปเดต 2026-11-09 · สำหรับ Rich ใช้ต่อฝั่ง deploy · ตัวเลขทั้งหมดสร้างใหม่ได้ด้วย `evaluate.py` (ผลอยู่ใน `eval_metrics.json`)

## 1. เปลี่ยนอะไร

อาจารย์ต้องการราคาที่ซื้อขายได้จริง หุ้น SET ขยับได้ทีละช่อง เช่นช่วง 200–400 บาทขยับทีละ 1.00 บาท ราคาอย่าง 338.6767 จึงใช้ไม่ได้

| ช่วงราคา (บาท) | < 2 | 2–5 | 5–10 | 10–25 | 25–100 | 100–200 | 200–400 | ≥ 400 |
|---|---|---|---|---|---|---|---|---|
| ช่องละ | 0.01 | 0.02 | 0.05 | 0.10 | 0.25 | 0.50 | 1.00 | 2.00 |

- `predict.py` มีฟังก์ชัน `to_tick()` ที่ปัดไปหาช่องราคาที่ใกล้ที่สุด ถ้าอยู่กึ่งกลางพอดีให้ปัดขึ้น
- **`prediction` = ราคาที่ปัดแล้ว ส่งค่านี้** ส่วน `prediction_raw` = ค่าดิบจากโมเดล เก็บไว้เป็นหลักฐาน
- `live.py` เขียนทั้งสองค่าลง `predictions.jsonl`
- โมเดล, feature และ hyperparameter ไม่ได้แก้เลย ปัดแค่ตอนส่งผลออก
- เช็กแล้ว: `python predict.py --selftest` ได้ "ok: 20 examples match, 21 tick cases pass" และ `python live.py --selftest` ผ่าน
  (ทดสอบราคาตรงรอยต่อระหว่างช่วงด้วย เช่น 199.76 → 200, 399.6 → 400, 400.9 → 400)

ตัวอย่างวันนี้ (09 พ.ย.): ADVANC 338.6767 → **339.00** · KBANK 241.6374 → **242.00**

## 2. วัดผลยังไง

- **RMSE เป็นตัวหลัก, MAE เป็นตัวรอง** หน่วยเป็นบาท ยิ่งต่ำยิ่งดี
- ตัวเทียบคือ "ราคาไม่ขยับ": รอบเช้าใช้ราคาปิดเมื่อวาน (หักปันผลถ้าวันนั้น XD) ส่วนรอบบ่ายใช้ราคาปิดภาคเช้า ซึ่งปัดเป็นช่องราคาเหมือนกัน
- "% ดีขึ้น" = RMSE (หรือ MAE) ลดลงกี่ % เทียบกับตัวเทียบ ค่าบวกแปลว่าโมเดลดีกว่า
- "ตรงเป๊ะ" = % ของวันที่ราคาที่ส่งตรงกับราคาจริงทุกสตางค์

วัด 2 ช่วง ทั้งสองช่วงเป็นการทายล่วงหน้าจริง ไม่มีวันไหนที่โมเดลเห็นคำตอบก่อนทาย

| ช่วง | วันที่ | วิธี |
|---|---|---|
| A. เดือนใหม่หลังเทรนใหม่ | 2026-09-07 → 10-21 (31 วันต่อหุ้น) | เทรนใหม่ทุกสัปดาห์ ด้วยข้อมูลก่อนวันแรกของสัปดาห์นั้น ใช้โค้ด fit กับ predict ชุดเดียวกับตอนรันจริง (เลือกโมเดลหลัก/สำรองและปัด tick เหมือนกันทุกอย่าง) |
| B. ช่วงยืนยันที่ล็อกไว้ | 2023-01 → 2026-09-04 (~890 วันต่อหุ้น) | ผลทายของ v9 ที่ล็อกไว้ (`v9-confirm-20261028-a`) แล้วเอามาปัดเพิ่ม |

ช่วง A ไม่มีข้อมูล S50 futures รอบเช้าจึงใช้โมเดลสำรอง (OLS × 0.7) ทุกวัน ซึ่งเหมือนตอนรันจริงที่ข้อมูลจาก Oanor ไม่มี futures เหมือนกัน

## 5. สรุปแบบตรงๆ

1. **รอบเช้ายังชนะ "ราคาไม่ขยับ" หลังปัดแล้ว**: ช่วงยืนยันดีขึ้น 3% ทั้งสองหุ้น ส่วนเดือนใหม่ ADVANC ดีขึ้น 6% แต่ KBANK แย่ลง 6%
2. **รอบบ่ายปัดแล้วแทบเท่ากับ "ราคาไม่ขยับ"** โมเดลบ่ายทายว่าราคาจะขยับน้อยกว่าครึ่งช่องเกือบทุกวัน
   พอปัดก็กลับไปเท่าราคาปิดภาคเช้า (93% ของวันในช่วงยืนยัน, KBANK ช่วง A ทุกวัน) ADVANC ช่วง A ที่ได้ +5.7% มาจากแค่ไม่กี่วัน
3. 31 วันต่อหุ้นยังน้อยเกินจะบอกได้ว่าดีหรือแย่จริง ตัวเลขที่เชื่อถือได้กว่าคือช่วงยืนยัน
4. ราคาดิบได้ RMSE ต่ำกว่าราคาที่ปัดในหลายแถว แต่อาจารย์ต้องการราคาที่ซื้อขายได้จริง **ส่งค่าที่ปัดแล้ว (`prediction`) เสมอ**
