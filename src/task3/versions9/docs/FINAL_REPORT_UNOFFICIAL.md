## 1. สรุปในหนึ่งหน้า

- **โจทย์:** ทุกวันซื้อขาย ทาย KBANK และ ADVANC หุ้นละ 2 ราคา คือ **ราคาปิดภาคเช้า** (ส่งก่อน 09:30) และ **ราคาปิดทางการ** (ส่งก่อน 13:00)
- **ตัวเทียบ:** รอบเช้า = ราคาปิดเมื่อวาน (หักปันผลวัน XD) · รอบบ่าย = ราคาปิดภาคเช้า
- **โมเดลที่เลือก:** รอบเช้า **Huber regression แยกรายหุ้น** · รอบบ่าย **HistGradientBoosting (HGB) รวมสองหุ้น**
- **ผลบนช่วงยืนยัน 2023-01 → 2026-09 (~890 วัน):** ทั้งสองรอบชนะตัวเทียบ ผ่านเกณฑ์ครบทุกข้อ

  | | รอบเช้า (Huber) | รอบบ่าย (HGB) |
  |---|---|---|
  | skill (MSE ลดลงจากตัวเทียบ) | **+6.43%** (CI 95% +3.5 → +9.5) | **+4.12%** (CI 95% +2.2 → +6.1) |
  | RMSE บาท KBANK: ตัวเทียบ → โมเดล | 1.755 → 1.696 | 1.003 → 0.981 |
  | RMSE บาท ADVANC: ตัวเทียบ → โมเดล | 3.102 → 3.003 | 1.906 → 1.869 |

- **ความหมายเชิงปฏิบัติ:** โมเดลลด error ได้จริงและมีนัยสำคัญ แต่ขนาดเล็ก (2–10 สตางค์ต่อวัน น้อยกว่า 1 tick)
  เพราะราคาส่วนใหญ่ขยับไม่เกิน 1–3 tick และตัวเทียบแม่นอยู่แล้ว
- **สิ่งที่ช่วยจริง:** รอบเช้า = ตลาดต่างประเทศข้ามคืน + การเด้งกลับของราคาที่ประมูลปิด (ATC) ดันไปเมื่อวาน
  · รอบบ่าย = การเคลื่อนไหวของหุ้นเองในภาคเช้า ผ่านโมเดลต้นไม้ที่จับความไม่เป็นเส้นตรงได้

## 2. โจทย์

| เรื่อง | ค่า |
|---|---|
| หุ้น | KBANK, ADVANC |
| รอบเช้า | ทาย `P_d` = ราคาซื้อขายล่าสุดของภาคเช้า (แท่ง 1m สุดท้ายที่จบไม่เกิน 12:30) · ส่งก่อน **09:30** |
| รอบบ่าย | ทาย `C_d` = ราคาปิดทางการของวัน d (ประมูล ATC 16:35–16:40) · ส่งก่อน **13:00** |
| จำนวนค่าทาย | 2 หุ้น × 2 รอบ = 4 ค่าต่อวัน · สัปดาห์สอบ 20 ค่า |
| ข้อบังคับ | ต้องเป็นโมเดลสถิติ / ML / DL · ตัวเทียบที่ไม่ใช้โมเดลส่งเป็นคำตอบไม่ได้ · ใช้ข้อมูลอะไรก็ได้ที่มีอยู่จริง ณ เวลาส่ง |

โจทย์นี้มาแทนโจทย์ "ทายราคาปิดพรุ่งนี้" ของ v1–v8 (อาจารย์เปลี่ยน 2026-10-26)

ทุกโมเดลทายเป็น log return เทียบราคาอ้างอิง แล้วแปลงกลับเป็นบาท (ไม่ปัดเป็น tick):

```
รอบเช้า:  y_m = log(P_d / (C_{d−1} − D_d))     P̂_d = (C_{d−1} − D_d) · exp(ŷ_m)
รอบบ่าย:  y_a = log(C_d / P_d)                  Ĉ_d = P_d · exp(ŷ_a)
```

`D_d` = ปันผลต่อหุ้นถ้าวัน d เป็นวัน XD ไม่งั้นเป็น 0

## 4. Feature

กติกาที่ใช้กับทุก feature:
- **ค่าต้องมีอยู่จริงก่อนเวลาตัดของรอบนั้น:** แท่งราคาใช้เวลาจบแท่ง · ราคาปิดทางการถือว่ารู้ 17:00 · futures หลังปิดถือว่ารู้ 17:15
  · ปันผลใช้วันประกาศ · ตลาดต่างประเทศใช้เวลาเปิด/ปิดของตลาดนั้น
- **ตัดค่าสุดโต่ง (clip)** ที่ percentile 1% / 99% ของหน้าต่างเทรน
- **ไม่เติมค่าที่หาย:** แถวที่ feature หายไม่ใช้เทรนหรือทาย

| รอบ | กลุ่ม feature | จำนวน |
|---|---|---|
| **เช้า** | ตลาดต่างประเทศข้ามคืน 5 ตัว · `atc_push` (ATC ดันราคาปิดเมื่อวานไปเท่าไร) · futures S50 หลังหุ้นปิด · return ข้ามคืนและระหว่างวันของเมื่อวาน · ช่วงราคา high–low · ปริมาณเทียบ 20 วัน · return หุ้นเพื่อน (KBANK) · วันจันทร์/หลังวันหยุดยาว · ปันผลวัน XD | KBANK 16 · ADVANC 15 |
| **บ่าย** | ทุกตัวของรอบเช้า + return ภาคเช้าของหุ้นเอง · ราคากระโดดตอนเปิด · return 30/60 นาทีสุดท้าย · `P_d` เทียบ VWAP · ช่วงราคาภาคเช้า · ปริมาณภาคเช้า · ทิศ tick ล่าสุด · return ภาคเช้าหุ้นเพื่อน · ดัชนีและ futures ภาคเช้า · ตัวบอกช่วงก่อน/หลัง 2024-03-25 | 31 (HGB ใช้ 23 ตัวที่เริ่ม 2017 + ตัวบอกหุ้น) |

**ข้อค้นพบระหว่างทำ feature:**
- **ตลาดต่างประเทศอธิบายราคากระโดดตอนเปิดได้ดี** (R² 0.28 KBANK, 0.20 ADVANC) แต่อธิบายราคาปิดภาคเช้าได้น้อยกว่ามาก (R² 0.10 / 0.02)
  เพราะช่วง 10:00–12:30 ราคาขยับเองอีกมาก
- **ATC ดันราคาปิดไปเท่าไร เช้าวันถัดไปราคาเด้งกลับราวครึ่งหนึ่ง:** สัมประสิทธิ์ ≈ −0.5 ถูกทางทุกการ fit ทั้งสองหุ้น
  จึงเก็บ `atc_push` ไว้ (log 2026-10-27)
- **ลองแล้วไม่ใช้:**
  - ราคากลาง bid/offer จาก SETSMART: ไม่เพิ่มอะไรเมื่อมี `atc_push` แล้ว
  - วันหมดอายุ futures: ATC ดันไม่ต่างจากวันปกติ
  - วันปรับน้ำหนักดัชนี: ดันแรงกว่า แต่ไม่บอกทิศ

**ตรวจข้อมูลรั่วจากอนาคต:**
- **วิธีตรวจ:** ตัดข้อมูลดิบทุกแหล่งทิ้งหลังเวลาตัด แล้วคำนวณ feature ใหม่ ค่าต้องเท่าเดิมทุกตัว
- **ผล:** ผ่านทั้ง 96 วัน-รอบที่สุ่ม และตอนตัดข้อมูลแล้วราคาที่ทายหายไปจริง จึงยืนยันได้ว่า test นี้ตรวจเจอการรั่ว
- **Opus ตรวจซ้ำเจอบั๊ก 1 จุด:** วันที่ของค่าเงินบาทเลื่อนไป 1 วันช่วงหน้าร้อนอังกฤษ

  - รันใหม่แล้วการตัดสินไม่เปลี่ยน

## 5. วิธีทดลอง

### 5.1 แบ่งข้อมูลตามเวลา

```
2017-04 ─ 2018 │ 2019 ─ 2022    │ 2023-01 ─ 2026-09-04  ║ 2026-09-07 ─ 10-30 │ 2026-11-09 ─ 11-13
เทรนอย่างเดียว  │ ช่วงเลือกโมเดล  │ ช่วงยืนยัน (เปิด 1 ครั้ง) ║ ซ้อมสอบ (ยังไม่ทำ)   │ สอบจริง
                                                       ╚ ล็อกโมเดล tag v9-prereg
```

- **expanding walk-forward:** เทรนด้วยข้อมูลทั้งหมดก่อนหน้า · **fit ใหม่ทุกสัปดาห์** ก่อนวันซื้อขายแรกของสัปดาห์
  (1D-CNN fit รายเดือนเพราะช้า)
- **hyperparameter เลือกปีละครั้ง:** แบ่ง 30% ท้ายของหน้าต่างเทรนเป็น 3 ช่วงตามเวลา แล้วเลือกค่าที่ MSE เฉลี่ยต่ำสุด
- **ตารางเดียวกันตลอด:** backtest ซ้อมสอบ และสอบจริงใช้กติกาเดียวกัน

### 5.2 Metric และสถิติ

- **หลัก:** RMSE เป็นบาท แยก 4 ค่า (2 หุ้น × 2 รอบ)
  - skill = `1 − MSE_โมเดล / MSE_ตัวเทียบ`
  - รวมสองหุ้นโดยหาร MSE ของแต่ละหุ้นด้วยราคาเฉลี่ยยกกำลังสองก่อน เพื่อให้ ADVANC ที่ราคาสูงกว่าไม่ครอบผลรวม
- **ทดสอบนัยสำคัญ:** Clark–West ด้านเดียว (Newey–West lag 5) · Holm ข้ามสองรอบที่ α = 0.05
- **ความไม่แน่นอน:** block bootstrap บล็อก 5 วัน 10,000 รอบ seed 340
- **รายงานอย่างเดียว ไม่ใช้เป็นเกณฑ์:** MAE · Mincer–Zarnowitz slope · skill รายปี · skill หลังตัดวันที่ได้มากสุด 1%

### 5.3 กฎการเลือกและการยืนยัน (ตั้งก่อนรัน)

1. **ช่วงเลือก:** เลือกโมเดลที่ skill สูงสุด
   - ถ้าโมเดลที่ง่ายกว่าแพ้ไม่ถึง 1 SE ของผลต่าง ให้เลือกตัวที่ง่ายกว่า
   - ลำดับความง่าย: OLS < ridge < Huber < HGB < MLP < CNN < ensemble
2. **ช่วงยืนยัน:** รันโมเดลที่เลือก **ครั้งเดียว** · ต้องผ่านครบ 3 ข้อ
   - Clark–West ผ่าน Holm
   - skill รวมเป็นบวก ≥ 2 ใน 3 ช่วง (2023 / 2024 / 2025–26) และ skill รายหุ้นไม่ต่ำกว่า −0.1%
   - ตัดวันที่ได้มากสุด 1% แล้วยังบวก
3. **ถ้าไม่ผ่าน:** ใช้โมเดลสำรอง `κ × OLS ตัวเล็ก` ที่เลือก κ ไว้บนช่วงเลือก โดยไม่กลับไปเลือกโมเดลใหม่

## 9. ข้อจำกัด

1. **ผลที่ได้เล็กเมื่อวัดเป็นบาท:** ลด RMSE ได้แค่ 2–10 สตางค์ ซึ่งน้อยกว่า 1 tick ถ้าปัดค่าทายเป็นราคาที่ซื้อขายได้จริง หลายวันจะกลับไปเท่ากับตัวเทียบ
2. **5 วันสอบน้อยเกินจะทดสอบสถิติ:** มีแค่ 5 ค่าต่อหุ้นต่อรอบ ผลสอบอาจแพ้ตัวเทียบได้เพราะโชค คำตอบว่าโมเดลดีจริงไหมมาจากช่วงยืนยัน (~890 วัน)
3. **รอบบ่ายอ่อนลง:** skill ลดทุกปีและครึ่งหนึ่งหลังเปลี่ยนเวลาเปิดภาคบ่าย ปี 2026 เหลือราว 3.4%
4. **ราคาช่วงยืนยันเคยเห็นแล้ว:** v5–v8 เคยดูราคาช่วงนี้กับเป้าอื่น ไม่ได้ใช้เลือกโมเดลของ v9 แต่ทีมรู้ภาพรวมตลาดช่วงนั้น
5. **รอบเช้าต้องมีราคา futures S50 หลังหุ้นปิดทุกวัน:** ถ้าวันไหนไม่มี Huber ทายไม่ได้ ต้องใช้โมเดลสำรอง
6. **KBANK รอบเช้าต้องมีราคาหุ้นธนาคารอื่นของเมื่อวาน** ด้วยเหตุผลเดียวกัน
7. **ไม่ได้ทดสอบ:** วันปรับน้ำหนักดัชนีแยก, การปัด tick, และผลของการ fit รายสัปดาห์เทียบรายเดือน
