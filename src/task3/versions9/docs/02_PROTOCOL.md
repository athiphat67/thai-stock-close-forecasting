## 3. โมเดลที่จะลอง (เพดาน)

สิ่งที่ทาย (ทุกโมเดลทายเป็น log return แล้วแปลงกลับเป็นบาท ไม่ปัดเป็น tick):

```
รอบเช้า:  y_m = log(P_d / (C_{d−1} − D_d))     P̂_d = (C_{d−1} − D_d) · exp(ŷ_m)
รอบบ่าย:  y_a = log(C_d / P_d)                  Ĉ_d = P_d · exp(ŷ_a)
```

## 4. ตัวเทียบ metric และความหมายของ "ชนะ"

### 4.1 ตัวเทียบ

| รอบ | ตัวเทียบหลัก | ตัวเทียบรอง (รายงานคู่) |
|---|---|---|
| เช้า | `P̂_d = C_{d−1} − D_d` (`ŷ_m = 0`) | `C_{d−1}` |
| บ่าย | `Ĉ_d = P_d` (`ŷ_a = 0`, ไม่หักปันผลซ้ำ) | `C_{d−1} − D_d` |

### 4.2 Metric

- **หลัก:** RMSE เป็นบาท แยก 4 ค่า (2 หุ้น × 2 รอบ) · skill = `1 − MSE_โมเดล / MSE_ตัวเทียบ`
  · รวมสองหุ้นในรอบเดียวกันด้วย skill ที่หาร MSE ด้วยราคาเฉลี่ยยกกำลังสอง แบบ v8 (K11)
- **รอง:** MAE · Mincer–Zarnowitz slope (ทายใหญ่หรือเล็กเกินไป) · % ทายทิศถูกเฉพาะวันที่ราคาเปลี่ยน
  · % วันที่ค่าทายห่างจากตัวเทียบเกินครึ่ง tick · skill รายปี · skill หลังตัดวันที่ได้มากสุด 1%
  · วัน XD แยก · รอบบ่ายแยกก่อน/หลัง 2024-03-25
- **metric รองใช้รายงานเท่านั้น ห้ามเป็นเกณฑ์ผ่าน** (เจ้าของ 2026-10-28, S4) · โดยเฉพาะ MAE: v4 ตั้ง MAE เป็นด่าน
  แล้วทุกโมเดลตกด่านนี้ด่านเดียว เพราะโมเดลที่ลด RMSE ขยับค่าทายออกจากตัวเทียบ ซึ่งเพิ่ม MAE เกือบเสมอ

### 4.3 สถิติ

- **เทียบกับตัวเทียบ** (โมเดลซ้อน เพราะตัวเทียบคือ ŷ = 0): Clark–West ด้านเดียว HAC (Newey–West lag 5)
- **เทียบโมเดลสองตัว** ที่ไม่ซ้อนกัน: Diebold–Mariano HAC lag 5
- **ครอบครัวหลัก** มี 2 ข้อ คือรอบเช้าและรอบบ่าย (skill รวมสองหุ้น) · Holm ที่ α = 0.05
- **หักผลจากการลองหลายแบบบนช่วงเลือก:** รายงาน skill ของแบบที่ดีที่สุด ลบ `σ̂·√(2 ln N)` (N = จำนวนสเปกที่ลองจริงของรอบนั้น,
  σ̂ = SE ของ skill จาก bootstrap ข้างล่าง) · **ใช้รายงานเท่านั้น ไม่ใช้เลือก** เพราะทุกสเปกในรอบเดียวกันถูกหักเท่ากัน
  อันดับจึงไม่เปลี่ยน (เจ้าของ 2026-10-28, S2) · หักมากกว่าที่ควร เพราะสเปกสัมพันธ์กันสูงและ `√(2 ln N)` สูงกว่าสูตรเต็ม
  ที่ N ≈ 10 ([04_REFERENCES](04_REFERENCES.md) §4 Bailey–López de Prado)
- **CI ของ skill:** block bootstrap บล็อก 5 วัน 10,000 รอบ seed 340 · สุ่มวันเดียวกันพร้อมกันทั้งสองหุ้น

## 5. การเลือกและการยืนยัน

   บนวันเดียวกัน จาก block bootstrap ชุดเดียวกับ §4.3 (เจ้าของ 2026-10-28, S1) · **ได้รอบละหนึ่งแบบ** และจดสเปกเต็มก่อนเปิดช่วงยืนยัน
